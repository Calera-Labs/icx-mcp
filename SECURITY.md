# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4.0 | :x:                |

## Reporting a Vulnerability

We take the security of our Volumetric Lattice Network and MCP connectors seriously. If you believe you have discovered a security vulnerability in this repository or the hosted Calera ICX infrastructure:

1. **Do not create a public GitHub issue.**
2. Email your vulnerability details, PoC, and impact analysis directly to:
   **`security@caleralabs.com`**
3. We will acknowledge receipt within 24 hours and coordinate responsible disclosure with you.
